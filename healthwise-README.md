# HealthWise

A Flask-based health prediction web app that uses machine learning models to assess health risks based on user input, helping users get quick, data-driven health insights.

## ✨ Features
- User-friendly form to input health parameters
- ML-based prediction for health risk assessment
- Instant results with clear, readable output
- Responsive web interface

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python (Flask)
- **Database:** MySQL

## ⚙️ Getting Started

### Prerequisites
- Python 3.x
- MySQL

### Installation
```bash
# Clone the repo
git clone https://github.com/atul004421/healthwise.git
cd healthwise

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

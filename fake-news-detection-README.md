# Fake News Detection System

A machine learning-based system that classifies news articles as real or fake, aimed at helping users identify unreliable content online.

## ✨ Features
- Text preprocessing and feature extraction from news articles
- ML classification model to predict real vs. fake news
- Simple web interface to test articles/headlines
- Displays prediction confidence

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python (Flask)
- **ML:** scikit-learn / NLP libraries (update based on what you actually used)

## ⚙️ Getting Started

### Prerequisites
- Python 3.x

### Installation
```bash
# Clone the repo
git clone https://github.com/atul004421/fake-news-detection.git
cd fake-news-detection

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

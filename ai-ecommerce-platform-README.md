# AI-Powered E-Commerce Platform

A full-featured e-commerce web application enhanced with AI-driven product recommendations, built to deliver a smarter, more personalized shopping experience.

## ✨ Features
- Product browsing, search, and filtering
- AI-based product recommendation engine
- User authentication and profile management
- Shopping cart and checkout flow
- Responsive design across devices

## 🛠️ Tech Stack
- **Frontend:** React, JavaScript, HTML5, CSS3
- **Backend:** Python (Flask)
- **Database:** MySQL

## ⚙️ Getting Started

### Prerequisites
- Node.js & npm
- Python 3.x
- MySQL

### Installation
```bash
# Clone the repo
git clone https://github.com/atul004421/ai-ecommerce-platform.git
cd ai-ecommerce-platform

# Install frontend dependencies
cd frontend
npm install
npm start

# Install backend dependencies
cd ../backend
pip install -r requirements.txt
python app.py
```
